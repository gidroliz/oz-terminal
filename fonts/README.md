# Шрифты

Шрифты хранятся локально, чтобы игра не зависела от Google Fonts и работала быстрее.

| Файл | Шрифт | Лицензия |
|---|---|---|
| `ubuntu-mono-cyrillic.woff2`, `ubuntu-mono-latin.woff2` | Ubuntu Mono (Dalton Maag) | [Ubuntu Font Licence 1.0](https://ubuntu.com/legal/font-licence) |
| `vt323-latin.woff2` | VT323 (Peter Hull) | [SIL Open Font License 1.1](https://openfontlicense.org) |

Файлы взяты из Google Fonts (подмножества cyrillic и latin).
